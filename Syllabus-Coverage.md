# Syllabus Coverage

Maps the **coaching module list** onto this repo, so you can tell at a glance whether a module is ready to revise from, and what is still missing if it isn't.

Use `Index.md` to find a *concept*. Use this file to check whether a *module* is done.

File names carry a **two-digit study-order prefix** (`01-Number-System.md` … `23-PnC-Probability.md`). The number is the order to cover them in, not the module number from your coaching list — the coaching numbers are the `#` column below.

## Legend

| | Meaning |
|---|---|
| ✅ | **Full** — covered at CAT depth. Revise from it as-is. |
| 🟡 | **Partial** — the core is there, but a named piece is missing. Usable, with a hole. |
| ⚪ | **Thin** — a foothold only. Do not revise from this yet. |
| ❌ | **Missing** — no coverage at all. |
| — | **Out of scope** — deliberately not tracked. |
