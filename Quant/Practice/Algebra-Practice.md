# Algebra — Practice Sets

> Companion to `Algebra.md`. Hints point to the section of the notes that contains the intended method — read the hint only after you've been stuck for a minute. Answer key with short solutions is at the bottom.
>
> **TITA** = type-in-the-answer (no options). **MCQ** = choose one.
>
> Suggested timing: 2.0 min/question for Sets A–H, and attempt the Mixed Set in one timed block.

## Set A — Identities & the x + 1/x chain

**A1.** (TITA) If x + 1/x = 4, find x² + 1/x².

*Hint: §1, the x + 1/x family, first link.*

**A2.** (MCQ) If x − 1/x = 3 and x > 0, then x + 1/x =

- (a) √11
- (b) √13
- (c) 5
- (d) √5

*Hint: §1, the last line of the x + 1/x family — the two squares differ by 4.*

**A3.** (TITA) If x + 1/x = 3, find x⁴ + 1/x⁴.

*Hint: §1 — go one link at a time; you cannot jump from x + 1/x to x⁴ + 1/x⁴ directly.*

**A4.** (MCQ) If a + b = 7 and ab = 10, then a³ + b³ =

- (a) 91
- (b) 133
- (c) 189
- (d) 243

*Hint: §1, the rearranged cube identity (a + b)³ = a³ + b³ + 3ab(a + b).*

**A5.** (TITA) If x² − 5x + 1 = 0, find x³ + 1/x³.

*Hint: §1 + §2 — divide the whole equation by x before you do anything else.*

## Set B — Quadratics

**B1.** (MCQ) If α and β are the roots of x² − 7x + 12 = 0, then α² + β² =

- (a) 13
- (b) 25
- (c) 37
- (d) 49

*Hint: §2, sum/product of roots and α² + β² = (α+β)² − 2αβ.*

**B2.** (TITA) If α and β are the roots of 2x² − 5x + 3 = 0, find 1/α + 1/β.

*Hint: §2, 1/α + 1/β = (α+β)/αβ. Don't find the roots.*

**B3.** (TITA) Find the maximum value of −2x² + 12x − 7.

*Hint: §2, Vertex — x = −b/2a. Do not differentiate.*

**B4.** (MCQ) The equation x² + kx + 9 = 0 has equal roots for

- (a) k = 6 only
- (b) k = ±6
- (c) k = ±3
- (d) k = ±9

*Hint: §2, discriminant D = 0. Watch the sign — the trap in the options is dropping the negative root.*

**B5.** (TITA) For how many values of k are both roots of x² − 6x + k = 0 positive integers?

*Hint: §2, sum and product of roots. List the integer pairs summing to 6.*

## Set C — Symmetric sums & cubics

**C1.** (TITA) If a + b + c = 10 and ab + bc + ca = 31, find a² + b² + c².

*Hint: §1, (a + b + c)² identity — the converter between the two symmetric sums.*

**C2.** (MCQ) If p, q, r are the roots of x³ − 6x² + 11x − 6 = 0, then 1/p + 1/q + 1/r =

- (a) 6/11
- (b) 11/6
- (c) 6
- (d) 11

*Hint: §3, cubic coefficient relations. Write the target as (pq + qr + rp)/pqr.*

**C3.** (TITA) If a + b + c = 6, ab + bc + ca = 11 and abc = 6, find a³ + b³ + c³.

*Hint: §5, the workhorse identity used forwards — a³+b³+c³ = 3abc + (a+b+c)(Σa² − Σab).*

**C4.** (TITA) If a + b + c = 0, ab + bc + ca = −7 and abc = 6, find a⁴ + b⁴ + c⁴.

*Hint: §1 and §3 — first get Σa², then get Σa²b² from (Σab)² = Σa²b² + 2abc·Σa, then use (Σa²)² = Σa⁴ + 2Σa²b².*

# Answer key

## Set A

**A1 — 14.** x² + 1/x² = (x + 1/x)² − 2 = 16 − 2 = **14**.

**A2 — (b) √13.** (x + 1/x)² = (x − 1/x)² + 4 = 9 + 4 = 13. Since x > 0, x + 1/x is positive, so it equals **√13**.

**A3 — 47.** x² + 1/x² = 3² − 2 = 7. Then x⁴ + 1/x⁴ = (x² + 1/x²)² − 2 = 49 − 2 = **47**.

**A4 — (b) 133.** a³ + b³ = (a+b)³ − 3ab(a+b) = 343 − 3(10)(7) = 343 − 210 = **133**.

**A5 — 110.** Divide x² − 5x + 1 = 0 by x: x − 5 + 1/x = 0, so x + 1/x = 5. Then x³ + 1/x³ = 5³ − 3(5) = 125 − 15 = **110**.

## Set B

**B1 — (b) 25.** α + β = 7, αβ = 12. α² + β² = 49 − 24 = **25**.

**B2 — 5/3.** α + β = 5/2, αβ = 3/2. So 1/α + 1/β = (5/2)/(3/2) = **5/3**.

**B3 — 11.** a = −2 < 0, so it has a maximum at x = −b/2a = −12/(−4) = 3. Value = −2(9) + 36 − 7 = **11**.

**B4 — (b) k = ±6.** Equal roots ⟹ D = k² − 4(1)(9) = 0 ⟹ k² = 36 ⟹ **k = ±6**. Both work; discarding −6 is the trap.

**B5 — 3.** Roots are positive integers summing to 6: (1,5), (2,4), (3,**3**). Products give k = 5, 8, 9 — three values.

## Set C

**C1 — 38.** (a+b+c)² = Σa² + 2Σab ⟹ 100 = Σa² + 62 ⟹ Σa² = **38**.

**C2 — (b) 11/6.** pq + qr + rp = c/a = 11 and pqr = −d/a = 6. So 1/p + 1/q + 1/r = **11/6**.

**C3 — 36.** Σa² = 36 − 22 = 14. Then a³+b³+c³ − 3abc = 6(14 − 11) = 18, so a³+b³+c³ = 18 + 3(6) = 36. (The roots are 1, 2, 3 — check: 1 + 8 + 27 = **36**.)

**C4 — 98.** Σa² = 0² − 2(−7) = 14. Σa²b² = (Σab)² − 2abc·Σa = 49 − 0 = 49. Then Σa⁴ = (Σa²)² − 2Σa²b² = 196 − 98 = **98**.

## Set D

**D1 — (c) √5 + 2.** Need m + n = 9, mn = 20 ⟹ m, n = 5, 4 ⟹ √5 + √4 = **√5 + 2**.

**D2 — 53.** x + y = (p² + q²)/2 = (81 + 25)/2 = 53. (Longhand: √x = 7, √y = 2 ⟹ 49 + 4 = **53**.)

**D3 — 16.** √(x + 9) = 9 − √x ⟹ x + 9 = 81 − 18√x + x ⟹ 18√x = 72 ⟹ √x = 4 ⟹ x = 16. Check: √25 + √**16** = 9 ✓.

**D4 — (b) 52.** x = 1/(2 − √3) = 2 + √3, so 1/x = 2 − √3 and x + 1/x = 4. Then x³ + 1/x³ = 4³ − 3(4) = 64 − 12 = **52**.

**D5 — (c) 5.** Multiply by (3 + √5)/(3 + √5): (14 + 6√5)/4 = 7/2 + (3/2)√5. So a = 7/2, b = 3/2 and a + b = **5**.

## Set E

**E1 — 162.** Brackets are −3, −3, 6, which sum to 0. So the value = 3(−3)(−3)(6) = **162**.

**E2 — (d) 36.** a + b + c = 0 ⟹ a³ + b³ + c³ = 3abc = **36**.

**E3 — -630.** Write as 7³ + 3³ + (−10)³. Bases sum to 0, so value = 3(7)(3)(−10) = **−630**.

**E4 — (c).** The identity gives (a+b+c)(a² + b² + c² − ab − bc − ca) = 0. Either the first factor is 0, or the second is — and the second is zero exactly when a = b = c. Both cases are possible, so only (c) must be true.

## Set F

**F1 — 12.** AM ≥ GM: (9x + 4/x)/2 ≥ √(9x · 4/x) = 6 ⟹ minimum **12**, at 9x = 4/x ⟹ x = 2/3.

**F2 — (a) −1 < x < 6.** −7 < 2x − 5 < 7 ⟹ −2 < 2x < 12 ⟹ **−1 < x < 6**.

**F3 — 100.** Fixed sum ⟹ product maximal when equal: 10 × 10 = **100**.

**F4 — (d) infinitely many.** The two critical points are −2 and 3, whose distance is exactly 5. For any x with −2 ≤ x ≤ 3 the two distances add to 5, so every such x is a solution.

**F5 — 5.** Case x < 1: (1−x) + (4−x) = 7 ⟹ x = −1 ✓ (lies in range). Case 1 ≤ x ≤ 4: gives 3 = 7, no solution. Case x > 4: (x−1) + (x−4) = 7 ⟹ x = 6 ✓. Sum = −1 + 6 = **5**.

## Set G

**G1 — (a) 11.** g(2) = 4, f(4) = 2(4) + 3 = **11**.

**G2 — -1.** x = 3: f(3) + 3f(1/3) = 12. x = 1/3: f(1/3) + 3f(3) = 4/3; multiply by 3: 3f(1/3) + 9f(3) = 4. Subtract the first: 8f(3) = −8 ⟹ f(3) = **−1**.

**G3 — 1/3.** f(f(x)) = (−2/(x+1)) ÷ (2x/(x+1)) = −1/x. So f applied four times returns x. Five applications = one application: f(2) = **1/3**.

## Set H

**H1 — 8.** Add the equations: 8x + 8y = 64 ⟹ x + y = **8**.

**H2 — (c) 6.** Need 2/4 = 3/k = 7/14. Since 2/4 = 1/2, we need 3/k = 1/2 ⟹ k = **6**.

**H3 — 70.** Adding: 7p + 7n = 490 ⟹ p + n = **70**.

## Mixed Set

**M1 — (b) 32.** (x − 1/x)² = (x + 1/x)² − 4 = 36 − 4 = **32**.

**M2 — -924.** Brackets 7, −11, 4 sum to 0 ⟹ value = 3(7)(−11)(4) = **−924**.

**M3 — (c) 9.** a = −1 < 0, maximum at x = −4/(−2) = 2; value = 5 + 8 − 4 = **9**.

**M4 — (c) 2√5.** 11 + 2√30 with m + n = 11, mn = 30 ⟹ 6, 5. So the expression = (√6 + √5) − (√6 − √5) = **2√5**.

**M5 — 23.** 81 = 35 + 2Σab ⟹ Σab = **23**.

**M6 — (b) 7.** α + β = p, αβ = 10, (α − β)² = p² − 40 = 9 ⟹ p² = 49 ⟹ p = **7** (p > 0).

**M7 — 10.** AM ≥ GM on x² and 25/x²: minimum = 2√25 = **10**, at x² = 5.

**M8 — (b) 6.** √(x+3) = 1 + √(x−2) ⟹ x + 3 = 1 + 2√(x−2) + x − 2 ⟹ 2√(x−2) = 4 ⟹ x − 2 = 4 ⟹ x = **6**. Check: 3 − 2 = 1 ✓.
