## How the generated files work

Every practice set and both interactive tests are **generated**, not hand-maintained. Each question lives exactly once, as data, and the generator emits both the Markdown and the HTML from it — so the two cannot drift apart.

| Source | Generator | Produces |
|---|---|---|
| `Quant/Practice/_build/topics/*.json` | `Quant/Practice/_build/gen_practice.py` | every `*-Practice.md` and the question bank inside `CAT-Quant-Test.html` |
| `VARC/Practice/_build/words.json` | `VARC/Practice/_build/gen_vocab.py` | `VARC/Vocabulary.md` and `VARC/Practice/Vocab-Trainer.html` |

To add or fix a question, edit the JSON and re-run the generator:

```bash
cd "Quant/Practice" && python3 _build/gen_practice.py
cd "VARC/Practice"  && python3 _build/gen_vocab.py
```

Both generators validate before writing: duplicate IDs, out-of-range answer indices, duplicate options, missing hints or solutions, and — where a question carries an optional `check` expression — the stated answer is recomputed and compared. A failure aborts the run rather than emitting a broken file.

**Do not hand-edit** any `*-Practice.md`, the `BANK` literal inside `CAT-Quant-Test.html`, or `Vocab-Trainer.html`. All of them are generated, and edits are overwritten on the next run. Change the JSON instead.

All 20 topics are now generated. The four that predated the generator — Algebra, Means & Weighted Averages, Mixtures & Alligation, and Ratio, Proportion & Variation — were folded in by `_build/migrate_legacy.py`, which merged the two copies that had existed in parallel. Where the wording had drifted, the fuller markdown version won. That script has done its job and is kept only as a record of the merge; it is not part of the build.

CAT Prep/
├── Index.md
├── Quant/
│   ├── *.md              ← one file per topic (22)
│   ├── Practice/         ← practice sets and the interactive test
│   │   └── _build/       ← question data + generator (source of truth)
│   └── Reference/        ← quick-reference material
└── VARC/
    ├── Vocabulary.md
    └── Practice/
        ├── Vocab-Trainer.html
        └── _build/       ← word data + generator (source of truth)
